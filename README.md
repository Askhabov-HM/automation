# automation

Репозиторий с личными рабочими автоматизациями.

Здесь каждая автоматизация живет в своей отдельной папке и решает одну понятную задачу: ускорить старт работы, убрать рутину и сократить количество ручных действий.

- [PDF Documents](pdf/README.md) — переносимый глобальный навык: Economy по умолчанию, Technical по явному запросу; одна команда сборки, JSON-отчёт, кеш и сравнение версий. Установка из Git: `python pdf/scripts/install_skill.py --setup`.
