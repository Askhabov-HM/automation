# Ресурсы примера

`earth.jpg`: фотография Земли с Apollo 17 (7 декабря 1972 года), NASA / экипаж Apollo 17.

Источник: https://images.nasa.gov/details/as17-148-22727

Изображение сохранено для автономного повторного использования в демонстрационном документе. Рабочие изображения добавляются отдельно; сам модуль не загружает URL из содержимого документа.

## Шрифты

В `fonts/` включены DejaVu Sans и DejaVu Sans Mono 2.37 (обычные, полужирные и наклонные начертания). Они обеспечивают кириллицу на компьютере без Arial/Consolas. Текст лицензии сохранён без изменений в `fonts/LICENSE`.

Официальный источник: https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37
